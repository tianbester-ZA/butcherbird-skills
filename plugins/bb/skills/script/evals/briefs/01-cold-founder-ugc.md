# Eval brief 1: a cold founder UGC ad

Client: whichever the person running the eval names, with no winners on file yet (to test the skill leaning on the passages alone). Load only that client's facts.

What it tests: the unaware row of the awareness table (opening describes the viewer, not the product), one flaw named, proof where the doubt forms, and a close a buyer can act on. Judge against a no-skill version, labels hidden.
