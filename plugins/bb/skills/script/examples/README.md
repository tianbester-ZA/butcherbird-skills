# Examples: a client's winners stay with that client

A client's own winners stay in that client's own folder and never cross clients. There is no shared swipe file here on purpose: a shared one would carry one client's ideas into another's work, and this repo goes to the whole team.

So nothing client-specific lives in this folder. Keep `winners.md` wherever you keep the client's work, and point the skill at it. A client with no winners on file yet: say so in `brief.md` and lean on the passages.

## What a winner entry holds

```
## <ad name> · <post id>
- hook as spoken: "<exact words>"
- first frame: <what's on screen in second one>
- why it won: <one line>
- number: <hook rate / hold rate / ROAS / purchases>, <date range>, from <Ads Manager or wherever it was read>
- passages behind it: <ids from that job's reasoning.md, if any>
```

Only from real results, with dated numbers. Nothing is added from memory, and nothing is invented to fill a file.
