# Examples: a client's edits stay with that client

A client's own winners stay in that client's own folder and never cross clients. There is no shared folder here on purpose, and this repo goes to the whole team, so no client's work lives in it.

Keep an `edits.md` wherever you keep the client's work: the edits the client or the team approved, by beat, with the file or post id, frame 0, where the cuts fell and why, and a dated number if there is one. Point the skill at it. A client with none gets none, and the edit leans on the passages instead.
